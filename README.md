# Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/Silas-N-Schlax/rm-prework-odin-admin-dashboard.git
```

Navigate to the project directory:

```bash
cd rm-prework-odin-admin-dashboard
```

Open `index.html` in your browser.

# Reflection

Key things learned from building this project:

* How to better use CSS Flexbox
* How to use CSS Grid
* How to combine the two for complex layouts

Things I would improve in a future iteration:

* More Dynamic UI
* Mobile UI
* No restrict to specific sizes for limited data.
